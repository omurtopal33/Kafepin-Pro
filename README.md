# KafePin Pro Update Center

Bu depo sadece KafePin Pro guncelleme paketleri icindir.

- Kafe veritabani, token, IP, Telegram bilgisi ve yedek kesinlikle yuklenmez.
- `latest.json` aktif surumu bildirir.
- Her yeni surumde sadece degisen dosyalari iceren `KafePin-Pro-Update-vX.zip` yuklenir.

KafePin Pro acilista bu depoyu kontrol eder. Yeni surum varsa Yonetim Merkezi'nde bildirim gorunur; `Yedekle ve Kur` dugmesi once emniyet yedegi alir, sonra sadece paket listesinde yazan dosyalari degistirir ve sunucuyu yeniden baslatir.
